## 独立环境到位后的执行顺序

1. 按 [独立联调手册](INTEGRATION.md) 准备专用数据库、测试样本、专用上传目录和沙箱配套凭据；不导入现用业务数据，不在聊天或 Git 中保存密钥。
2. 先运行前置检查，确认数据源、端口与目录，再启动关闭业务定时任务的隔离后端；执行只读商品与资讯冒烟。空库成功响应不能算业务验收通过。
3. 按下面验收矩阵逐项执行，记录版本、样本、预期、实际及证据。默认库存模式先验收；预占模式须先审查迁移并统一实例配置。
4. 有意测试拼团到期和退款恢复时，核对测试数据及渠道配置后显式开启任务。重复退款始终使用稳定请求号，核对沙箱与本地结果。
5. 失败项先修复并重跑相关场景；全部必要场景有证据通过后，才能认定该测试环境的真实业务验收通过。
